# Maria's Professional Portfolio

## Files
- `index.html` — website structure/content
- `style.css` — design and responsive layout
- `script.js` — animations, typing effect, theme, menu and contact form
- `assets/maria-profile.jpg` — profile photo

## IMPORTANT: add your real contact details
Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_USERNAME`

Also update the same email inside `script.js`:
- `const destination = "YOUR_EMAIL@example.com";`

Replace the social links with your actual Instagram, LinkedIn and GitHub URLs.

## Run locally
Open the folder in VS Code and open `index.html` in a browser.
For a better development workflow, use the VS Code Live Server extension.

## Publish online
GitHub Pages can host this static HTML/CSS/JavaScript website. Create a repository and publish the site from the repository's Pages settings.

## Important privacy note
Only put information online that you are comfortable making public. Do not publish passwords, private documents, payment details, or other sensitive information.
